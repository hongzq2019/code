# 大乐透历史衰减概率模型设计

## 目标

在现有逻辑回归、向量转移和动态集成模型之外，新增独立的第 4 种预测模型“历史衰减概率”。模型使用全部历史开奖，分别计算前区和后区号码的指数时间衰减出现概率，推荐概率最高的前区 5 个号码和后区 2 个号码。

动态集成继续只融合逻辑回归与向量转移，不把新模型纳入集成权重搜索。前端仍默认显示动态集成结果，用户可通过模型下拉框切换查看历史衰减概率结果。

## 算法定义

模型类型命名为 `DECAYED_FREQUENCY`，算法版本为 `decayed-frequency-v1`。

开奖记录按开奖日期和数据库 ID 升序排列。对一组包含 `N` 期的历史数据，最新一期的期龄为 `0`，上一期为 `1`，依次递增。第 `age` 期历史开奖的权重为：

```text
weight(age) = 0.5 ^ (age / 200)
```

半衰期固定为 200 期：距离最新一期 200 期的权重为 `0.5`，400 期为 `0.25`。

前区与后区独立统计。对候选号码 `number`：

```text
probability(number) =
    sum(weight(age) for draws containing number)
    / sum(weight(age) for all draws)
```

前区生成 1–35 的完整概率表，后区生成 1–12 的完整概率表。按概率降序选择前区 5 个、后区 2 个；概率相同时按号码升序保证结果可复现，最终号码按自然升序返回。

## 训练与滚动验证

新增独立训练器，在与现有模型相同的五段滚动验证区间上进行回测。预测目标期 `targetIndex` 时，只允许使用 `[0, targetIndex)` 的开奖记录计算概率，禁止目标期和未来数据进入特征或概率统计。

每个验证期生成完整的 35 个前区概率和 12 个后区概率，并复用现有指标计算器，统计：

- 前区和后区二元 LogLoss；
- 前区平均命中数和后区平均命中数；
- 对应随机概率基线；
- 前区和后区是否优于至少一项随机基线。

完成回测后，使用训练水位内的全部历史开奖重新计算生产概率。生产预测直接读取训练产物中保存的概率表，不在请求时重新统计，保证返回结果与模型版本、训练水位一致。

## 模型产物

模型产物采用版本化 JSON：

```java
public record DecayedFrequencyArtifact(
        int artifactVersion,
        int halfLifeDraws,
        Map<Integer, Double> frontProbabilities,
        Map<Integer, Double> backProbabilities) {
}
```

固定参数：

- `artifactVersion = 1`；
- `halfLifeDraws = 200`；
- 前区概率必须完整覆盖 1–35；
- 后区概率必须完整覆盖 1–12；
- 每个概率必须是有限数值且位于 `[0, 1]`。

模型参数缺失、版本不支持或概率非法时，预测接口返回 HTTP 503，不生成随机兜底结果。

## 批次存储与激活

`PredictionModelType` 新增 `DECAYED_FREQUENCY`。完整生效批次从三种模型扩展为四种模型：

1. `LOGISTIC_REGRESSION`；
2. `VECTOR_TRANSITION`；
3. `DYNAMIC_ENSEMBLE`；
4. `DECAYED_FREQUENCY`。

四条模型记录必须共享相同的 `batchVersion`、训练开奖 ID、期号和日期，才能原子激活。任意训练、序列化或持久化失败均保留旧生效批次。

新增 Flyway 迁移，删除并重建 `prediction_model` 的模型类型检查约束，使其接受 `DECAYED_FREQUENCY`。同步更新完整初始化脚本。迁移不删除或改写已有三模型历史记录。

自动重训、启动水位检查和管理员手动重训沿用现有触发流程，但一次训练必须生成四个候选模型。动态集成是否满足启用条件仍决定批次是否替换已有生效批次；首次没有生效批次时允许激活完整四模型批次。

## 预测接口

`POST /api/v1/dlt/predictions` 固定按以下顺序返回四种模型结果：

1. 逻辑回归；
2. 向量转移；
3. 动态集成；
4. 历史衰减概率。

历史衰减概率结果与其他模型使用相同的 `ModelPredictionResponse`，包含号码、完整前后区概率表、模型版本、训练时间、训练水位、样本期数和验证指标。其 `ensembleWeights` 为 `null`。

生效批次仍为旧三模型批次时，因批次不完整返回 HTTP 503，并提示管理员重新训练；不混用不同批次或不同水位的模型。

## 前端与管理端

预测页模型下拉框新增“历史衰减概率”，默认选项仍为“动态集成（主推荐）”。一次请求加载四组结果，切换选项只读取本地结果，不重复请求接口，页面始终只展示当前选择的一组号码。

历史衰减概率卡片展示：

- 前区 5 个和后区 2 个号码；
- 模型版本、依据期号、训练水位和样本期数；
- 前后区 LogLoss 与平均命中数；
- 共用风险提示。

管理端手动重训结果表由三行扩展为四行，并把 `DECAYED_FREQUENCY` 映射为“历史衰减概率”。数据同步、训练状态和错误状态继续相互独立。

## 验证范围

后端验证重点：

- 最新一期权重为 `1`，200 期期龄权重为 `0.5`；
- 前后区概率计算、完整候选范围和稳定排序正确；
- 修改目标期或未来期不会改变该目标期预测；
- 生产产物保存全部概率且通过边界校验；
- 缺少任一模型或混合批次不能激活；
- 四种模型训练成功时只执行一次批次激活；
- 预测接口按固定顺序返回四组结果。

前端验证重点：

- TypeScript 类型与四模型响应一致；
- 模型下拉框包含历史衰减概率；
- 默认仍选择动态集成；
- 切换模型不重复请求；
- 管理端训练表正确显示四种模型。
